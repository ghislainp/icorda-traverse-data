


This dataset contains measurements of snow specific surface area (SSA) and snow density collected at Little Dome C, in Antarctica, by Marine Poizat and Ghislain Picard during the "Icorda" traverse in 2022-2023.


# ./profiles/

Files (csv format) with snow properties profiles.

- z: depth (m)
- density: snow density (kg/m3)
- ssa (sample): no data
- ssa (run): specific surface area measured with Asssap in profile mode (m2/kg)
- newrun: indicate a change of core.

The density data are resampled onto the SSA data (higher resolution).
